# Shaun Michael Belono-ac — Portfolio

This portfolio has been migrated from the original static HTML/CSS site to Next.js with Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Production

```bash
npm run build
npm run start
```

The migrated app lives in `app/`. Local images and the resume PDF are served from `public/img/`. The original HTML/CSS files are kept in place as a reference during the migration.
